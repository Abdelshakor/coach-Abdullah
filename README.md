## 🔗 تعديل روابط صور التحولات

لربط كل صورة ببوست انستجرام معين:

### الخطوات:
1. افتح ملف `index.html`
2. ابحث عن `LINK_1` (استخدم Ctrl+F)
3. استبدله برابط البوست من انستجرام

### مثال:
**قبل:**
```html
<a href="LINK_1" target="_blank" class="trans-item animate-on-scroll">
```

**بعد:**
```html
<a href="https://www.instagram.com/p/ABC123xyz/" target="_blank" class="trans-item animate-on-scroll">
```

### الروابط المطلوب تغييرها:
| ابحث عن | استبدله برابط |
|---------|---------------|
| `LINK_1` | رابط بوست الصورة 1 |
| `LINK_2` | رابط بوست الصورة 2 |
| `LINK_3` | رابط بوست الصورة 3 |
| `LINK_4` | رابط بوست الصورة 4 |
| `LINK_5` | رابط بوست الصورة 5 |
| `LINK_6` | رابط بوست الصورة 6 |
| `LINK_7` | رابط بوست الصورة 7 |

## 📱 تعديل رقم الواتساب

### الخطوات:
1. افتح ملف `index.html`
2. ابحث عن `201146165846`
3. غيره لرقمك (بدون + أو 00)

### الأماكن الموجود فيها الرقم:
- زر الواتساب العائم
- رابط الفوتر
- فورم الاشتراك

### مثال:
لو رقمك `+20 1234567890` اكتبه كده: `201234567890`

## 🎨 تغيير اللون الأحمر الرئيسي

### الخطوات:
1. افتح ملف `style.css`
2. في أول الملف ستجد:
```css
:root {
    --primary-red: #DC2626;
    --primary-red-dark: #B91C1C;
```
3. غير `#DC2626` للون المطلوب

### ألوان مقترحة:
| اللون | الكود |
|-------|-------|
| أحمر (الحالي) | `#DC2626` |
| أزرق | `#2563EB` |
| أخضر | `#16A34A` |
| برتقالي | `#EA580C` |
| بنفسجي | `#9333EA` |

## 🚀 رفع الموقع على GitHub Pages

### الخطوات:
1. أنشئ Repository جديد على GitHub
2. ارفع جميع الملفات (index.html, style.css, script.js, images/)
3. اذهب إلى Settings > Pages
4. اختر Branch: main
5. اضغط Save
6. انتظر دقيقة وسيعمل الموقع على:
   `https://username.github.io/repository-name/`

## ☁️ ربط الموقع بـ Cloudflare

### الخطوات:
1. سجل في [Cloudflare](https://cloudflare.com)
2. أضف موقعك (Add Site)
3. اختر الخطة المجانية
4. غير DNS في مزود الدومين لـ Cloudflare
5. فعّل SSL/TLS (Full)
6. فعّل Auto Minify للـ HTML, CSS, JS

## 🔄 تغيير سرعة تبديل الصور

### الخطوات:
1. افتح ملف `script.js`
2. ابحث عن:
```javascript
}, 2500); // تبديل كل 2.5 ثانية
```
3. غير الرقم `2500` للسرعة المطلوبة (بالمللي ثانية):
   - `1000` = ثانية واحدة
   - `2000` = ثانيتين
   - `3000` = 3 ثواني
   - `5000` = 5 ثواني
